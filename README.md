# Lumbangan National High School SBM Portal

Official School-Based Management portal for browsing SBM dimensions, indicators, sub-indicators, and Means of Verification (MOVs). The site provides links to the school's Google Form for file submissions and shared Google Drive folder for reviewing uploaded files.

## Files

- `index.html` — complete website
- `LNHS_LOGO-removebg-preview.png` — school logo used in the header

## Publish with GitHub Pages

1. Create a GitHub repository and upload both website files and this README.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub to display the published website address.

Keep `index.html` and the logo image in the same folder so the logo loads correctly.
